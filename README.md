# 电力技术规范智能问答助手

> 
> 基于 RAG 检索增强生成技术的电力行业垂直知识库问答系统

本项目是一套面向电力行业的技术规范智能问答解决方案，通过大语言模型 + 向量检索技术，实现电力标准文档的精准问答、自动分类、知识库管理等能力，支持 PDF / DOCX 格式规范文档一键入库，系统自动匹配类目并给出基于原文的严谨回答，有效降低规范查阅成本，提升技术人员工作效率。

项目采用 Spring Boot + Vue 3 前后端分离架构，支持一键合并打包为单 Jar 部署，适配政企项目驻场交付、内网私有化部署场景。

---

## ✨ 功能特性

### 核心能力

- **智能问答**：基于 RAG 检索增强生成，回答严格依据上传的规范文档，减少大模型幻觉，回答可溯源
- **自动分类**：文档上传与用户提问均由 AI 自动识别所属技术类目，对用户屏蔽分类概念，使用零门槛
- **知识库管理**：支持 PDF / DOCX 格式文档上传，自动切片向量化入库，支持内存版与持久化向量库双模式
- **结构化输出**：回答自动按「结论 + 规范依据 + 补充说明」格式输出，符合电力行业专业阅读习惯

### 工程特性

- **前后端一体部署**：支持开发期分离调试、打包期自动合并，最终产出单个可执行 Jar，部署零依赖
- **多模型适配**：聊天与向量化解耦配置，默认 DeepSeek 对话 + 通义千问嵌入，可灵活替换其他兼容 OpenAI 协议的模型
- **国网风格界面**：采用电力行业主流浅绿配色体系，界面简洁专业，符合政企系统视觉规范
- **平滑升级路径**：内存向量库可无缝升级为 Milvus 持久化向量库，业务代码零改动

## 🛠 技术栈

### 后端

- **框架**：Spring Boot 3.2.x
- **AI 能力**：Spring AI 1.0.x
- **大模型**：DeepSeek Chat（对话）、通义千问 Embedding（向量化）
- **向量存储**：SimpleVectorStore（内存版）/ Milvus（持久化版）
- **文档解析**：Apache PDFBox、Apache POI
- **构建工具**：Maven

### 前端

- **框架**：Vue 3 + Vite
- **UI 组件**：Element Plus
- **HTTP 客户端**：Axios
- **设计风格**：国网绿政企主题

## 🚀 快速开始

### 环境要求

- JDK 17+
- Node.js 16+
- Maven 3.6+

### 后端启动

1. 克隆项目到本地
2. 修改 `src/main/resources/application.yml` 配置
```
spring:
  ai:
    openai:
      base-url: https://api.deepseek.com
      api-key: 你的DeepSeek API Key

tongyi:
  embedding:
    api-key: 你的通义千问API Key
    model: text-embedding-v2
```
3. 执行 Maven 刷新，启动启动类 `PowerSpecAiApplication`
4. 后端服务默认端口：`8080`

### 前端启动

1. 进入前端目录 `power-spec-ai-web`
2. 安装依赖
```
npm install
```
3. 启动开发服务
```
npm run dev
```
4. 访问地址：`http://localhost:3000`

### 接口验证

- 问答接口：`POST /api/spec-qa/ask`
- 文档上传：`POST /api/spec-qa/upload`

## 📦 部署方式

### 方式一：前后端合并部署（推荐）

1. 前端执行 `npm run build` 打包
2. 将 `dist` 目录下所有文件复制到后端 `src/main/resources/static` 目录
3. 后端执行 `mvn clean package` 打 Jar 包
4. 启动命令：
```
java -Xms256m -Xmx768m -jar power-spec-ai-assistant.jar
```
5. 访问 `http://服务器IP:8080` 即可同时使用前端页面和后端接口

### 方式二：分离部署

- 前端打包后通过 Nginx 部署，配置反向代理到后端接口
- 后端独立 Jar 包部署，适合生产环境横向扩展

## 🔧 扩展方向

1. **持久化向量库**：升级 Milvus 向量数据库，支持海量规范文档存储，重启数据不丢失
2. **扫描件 OCR**：接入云端 / 本地 OCR 能力，支持扫描版 PDF 规范文档识别入库
3. **多轮对话**：引入对话上下文记忆，支持连续追问与多轮交互
4. **权限体系**：增加用户登录、角色权限、操作审计，适配企业级使用场景
5. **回答溯源**：精确标注回答对应的文档页码与条款编号，点击可跳转原文定位
6. **批量管理**：支持文档批量上传、分类管理、删除编辑、版本控制

---

## 📝 注意事项

1. 内存版向量库仅用于开发调试，应用重启后上传的文档数据会丢失，正式使用请切换 Milvus
2. 电力规范文档建议使用可复制文字的电子版 PDF，扫描件需额外接入 OCR 能力
3. 大模型 API Key 请妥善保管，生产环境建议通过配置中心或环境变量注入，不要硬编码提交到代码仓库
4. 项目默认仅支持中文电力技术规范问答，超出知识库范围的问题模型会明确提示，禁止编造
